# Artificial Pancreas Control Lab — Interactive Streamlit App

## Features
- Responsive dark-mode interface for desktop and mobile.
- Searchable bundled food catalog covering Indian meals, continental foods, fast food/snacks, sweets/desserts, drinks, fruit, and basic foods.
- Food + quantity meal entry, with estimated calories, carbohydrates, sugar, protein, and fat derived from the bundled per-100 g/ml food catalog.
- Existing six-hour (0–6 h) experiment workflow, controller comparison, metrics, and CSV export.
- PID, constrained PI with insulin-on-board (IOB) protection, and LQR + observer controllers.
- **New Continuous monitor tab:** independent session state, one-second UI refresh, expanding elapsed-time axis, start/pause/resume/reset, current-time meal logging, glucose and insulin-delivery traces, plasma-insulin and IOB traces, meal-event history, and CSV export.
- Eight project phases, tests, generated result files, and report are included.

## Easiest way to run on Windows
Extract the ZIP, open the extracted folder, and double-click `START_HERE.bat`. It creates a local `.venv`, installs `requirements.txt`, and starts Streamlit. Keep the terminal window open while using the app.

## Manual run
From the project root:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Run the numerical project and tests

```bash
python run_all.py
python -m unittest discover -s tests -v
```

## Continuous monitor behaviour
The additional tab runs an independent Bergman-model simulation. It begins at the configured basal equilibrium. When a meal is logged, the food and quantity are converted to a carbohydrate disturbance and timestamped at the monitor's current simulated time. The selected controller calculates the simulated insulin-delivery command. The time axis grows throughout the active browser session instead of stopping at the original six-hour horizon.

The simulation pace is selected before starting; for the continuous monitor it also determines the controller sampling interval. The existing experiment's settings and state remain separate.

## Food data
The bundled food database contains practical nutrition estimates. Mixed dishes, restaurant portions, brands, and recipes vary. The catalog is not a verbatim bulk copy of USDA FoodData Central or the ICMR–NIN Indian Food Composition Tables. References: [USDA FoodData Central](https://fdc.nal.usda.gov/) and [ICMR–NIN IFCT 2017](https://www.nin.res.in/ebooks/IFCT2017.pdf).

## Important limitation
This is an educational control-systems simulation, not a medical device. The continuous monitor displays glucose generated by the Bergman model from an assumed basal starting state; it does **not** measure a person's actual blood glucose and is not connected to a CGM. The insulin-delivery curve is a simulated controller command; it does **not** control a physical insulin pump. Do not use the app for treatment decisions or insulin dosing.

## Deployment
For Streamlit Community Cloud, keep `app.py`, `food_database.csv`, `requirements.txt`, and the `ap/` package in the repository root. The continuous monitor uses Streamlit fragments and the listed Streamlit dependency. Do not commit `.venv/`.
